要一起改的三件事

  • 数据：新建 user_tags(id, name) + word_user_tags(wordId, tagId)，原来的 words.tags 不再写入用户标签。
  • 搜索：headword / meanings / user_tags 三段合起来匹配，命中标签时单独提示一条。
  • 学习页：加标签弹窗只列用户标签，并支持当场新建；搜索框自动聚焦弹键盘。

列表行只留三样东西

  • 左：词头 + 词性 + 一行释义；
  • 下：用户标签（彩色小块，最多两三个）；
  • 右：状态（未学 / 学习中 / 已掌握 / 已移出）+ 下次复习日期。

可以再讨论的点

  • 「我的标签」是放在筛选区常驻，还是收进「筛选」按钮里（省高度）？
  • 标签要不要配色？（现方案按创建顺序自动分配 5 种柔和色）
  • 词表 / 状态 / 标签三者是与关系还是标签单独覆盖？现在是「与」，标签可多选。
