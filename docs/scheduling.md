# 记忆算法与学习流程

调度基于 SM-2 改造：**分钟级学习步** + **天级复习间隔**，两套节奏用同一个「距 epoch 的分钟数」字段比较，排序与筛选都在 SQL 里完成。

## 参数

设置 → 每日计划 / 学习步与毕业 / 算法参数。

| 参数 | 默认值 | 作用 |
|---|---|---|
| 每日新词上限 | 20 | 每天引入多少没学过的词；设 0 表示只复习 |
| 每日复习上限 | 200 | 今天最多发多少张**复习卡**。按今天已经「过过一遍」的旧卡数扣减（忘记 / 模糊也算过卡，同一张卡当天多次只算一张），额度用完当天不再发复习卡。学习步里的卡是在途的卡，不受它影响 |
| 每组词数 | 10 | 连答这么多张弹一次单词小结，只影响节奏 |
| 新词抽取顺序 | 按词频排名 | 按词频 / 按入库顺序 / 随机 / 按难度混合 / 按词表比例。标了「优先学」的词永远先抽 |
| 难度混合比例 | 5:3:2 | 仅「按难度混合」：按 COCA 排名把范围内新词三等分为易/中/难，按比例交错抽取 |
| 参与抽取的词表 | 不限 | 仅「按词表比例」：一个都不勾 = 不限制词表 |
| 学习步（分钟） | `1,10` | 新词在学习阶段的重考间隔，走完最后一步才毕业 |
| 毕业间隔 | 1 天 | 学习步走完后第一次天级复习的间隔 |
| 初始难度系数 | 2.5 | 每个新词的起始 ease |
| 「模糊」间隔倍数 | 1.2 | 按模糊时间隔乘的系数 |
| 全局间隔修正 | 1.0 | 所有天级间隔统一乘这个数 |
| 最小 / 最大间隔 | 1 / 365 天 | 间隔上下限 |
| 挂起阈值 | 8 | 累计「忘记」多少次后自动移出队列 |

所有参数都做范围校验，越界会被收敛回合法区间。点「恢复默认参数」不会动词库与进度。

**「按词表比例」**按各词表的**未学词数**分配名额，并按勾选顺序先到先得去重；每个勾选词表至少分到 1 个名额（名额够分时），避免小词表永远抽不到。

**「优先学」**压过所有顺序：词库详情页给未学词打开开关后，下一次抽新词先把它抽出来，抽走即自动移除。

## 学习流程

### 首页

- 当前学习词表 + 已学比例与进度条
- 两行计数：
  - `今日新词 · 初学 x / 掌握 y / 上限 z`
  - `复习词 · 已复习 x / 需巩固 y / 待复习 z`
- 通栏大按钮：今天还没作答是「开始学习」，答过是「继续学习」，没卡可学则置灰并说明

### 计数口径

| 数字 | 含义 |
|---|---|
| 初学 | 今天开始学的词：今天新学的 ∪ 今天忘了又重新学起来的。后者**要等重新答对才算**；标「太难」的新词不算 |
| 掌握 | 上面那些里今天已经学完的（含重学完的、标「太简单」的） |
| 上限 | 每日新词上限 − 今天标「太难」的新词数 |
| 已复习 | 今天答过「认识」的旧词 + 今天被移出学习的旧词 |
| 需巩固 | 仍在学习步内（LEARNING / RELEARNING）的卡 |
| 待复习 | 今天还发得出来的复习卡（按每日上限剩余额度截断）+ 学习步里已经到期的卡 |

### 卡片页

正面只有单词和音标，先回忆；点「不认识 / 我认识」先预选档位，揭晓后确认或改判。点空白处是普通揭晓。

揭晓后按字段配置显示释义、巧记、词根词缀、变形、例句，底部三档评分，按钮上直接印着**按下之后的下次间隔**。

**「模糊」= 考到认识为止的循环。** 复习卡点「模糊」时排期按模糊算一次并**当场定死**，卡片被插到第 10 个词之后再考：继续模糊就继续隔 10 个词回来，直到点「认识」才放走。定死之后——再模糊不重算间隔、认识不改间隔、忘记则排期重算并退回重学。新词第一次学不走这套。

**「太简单」/「太难」不是评分档**，而是移出学习（分别进词库的两个名单，可一键移回）。因为不可逆，按下后卡片停在原地：行上的按钮变成「撤销」，底部变成「下一个」——撤销可恢复到标记前的状态。这两个动作不写作答日志，但旧词算「已复习」；用在新词上则是「太简单 → 初学 +1、掌握 +1；太难 → 扣一个名额」。

**单词小结**：每连续作答若干张（默认 10）弹一次，把这组的词形、词性、释义排在一起回看。

**发音**：优先播 `assets/pron/<单词>.mp3` 里的真人录音，查不到回落系统 TTS；全程不联网、不需要权限，失败静默降级。

## 复习排期与手动改期

词条详情页的状态徽章可以点，弹窗输入「几天后」（0 = 今天）。这个入口**只对学过的词开放**：新词在 `review_states` 里没有行，给它设到期日会凭空建行，让词从新词队列里消失。

设完后到期时刻落在当天零点（与天级间隔的取整方式一致），状态置为 `REVIEW`、学习步下标归零；不写作答日志。

时间文案由 `domain/srs/ReviewSchedule.kt` 统一换算：过期说「已到期」，当天 / 明天 / 30 天内按天，再远按月、年。

## 卡片页顶部的今日进度条

- 分母 = 今日复习的分母（已按每日上限截断）+ 新词上限（已扣掉「太难」）
- **深绿** = 已复习 + 掌握
- **浅绿** = 模糊待重考 + 初学未掌握
- 其余无色 = 今天还没做的
