# 用 AI 给词库补「巧记 / 词根词缀 / 变形」

`k3y-考研词库-L0-L2.csv` 里没有应用主打的那三列。这份提示词让 AI 按 `docs/sample-vocab.csv` 的风格补上。

## 用法

1. 把下面「提示词」整段复制给 AI（Claude / GPT 都行）。
2. **分批喂**：一次 30–50 行，别一次给 3265 行 —— 模型会开始偷懒、漏行、或者悄悄改掉别的列。
3. 每次拿到结果，抽查 5 行再合并，别攒到最后一起查。
4. 合并后重新导入应用验证。

---

## 提示词

复制以下全部内容（含分隔线之间的一切）：

~~~~
你是一位考研英语词汇教研老师。我给你一批考研单词（CSV），你要为每个词补上三列内容，**其他列一个字都不许动**。

## 输入格式

CSV，表头固定为：

    word,pos,meaning,tags,frequency,example,deck

- `meaning` 可能是多行（字段内换行分隔），多个词性会内联在释义行里，例如 `adv. 大约；在附近`
- `example` 是「英文原句 + 空格 + 中文译文」拼成的一行
- 以上这些列**逐字保留**，包括标点、空格、换行。不要润色，不要重译，不要调整顺序。

## 你要新增的三列

### mnemonic（巧记）
拆词 + 逻辑推导，让人看出「为什么这个词是这个意思」。

格式：`词素(含义)+词素(含义)，推导→结论`

- 例：`ab(离开)+sent(存在)，人不在场→缺席`
- 例：`se(没有)+cur(关心)+ity(状态)，没有忧虑并受到保护的状态→安全`

### root（词根词缀）
把词拆成前缀 / 词根 / 后缀，**每个都带含义**，用 ` + ` 连接。

写法：前缀 `ab-`、词根 `-sent-`、后缀 `-ity`，后面跟一个空格再跟中文含义。

- 例：`ab- 离开 + -sent- 存在`
- 例：`se- 没有 + -cur- 关心 + -ity 状态`

### derivation（变形）
同根派生词，格式 `单词 词性 释义`，多条用 `；` 分隔，**最多 3 条**，挑最该记的。

- 例：`absence n. 缺席；absent-minded adj. 心不在焉的`

### synonyms（近义词）
同义、近义的词，多个用 `；` 分隔，**最多 3 个**。

**关键约束：只能从下面这份词表里挑。** 我会把整批词的清单附在末尾，你只能从中选。
一个近义词如果不在那份清单里，导入时会被直接丢弃 —— 写了等于白写，还浪费 token。

- 例（假设清单里有 effect 和 influence）：`effect；influence`
- 如果清单里找不到合适的近义词，**留空**，不要写清单外的词。

## 铁律

1. **不确定就留空。** 这是最重要的一条。词源学上编造比留空有害得多 —— 一个错误的词根会让人形成错误的记忆，而且学习者没有能力自查。
   - `about` / `the` / `of` / `and` 这类常用虚词通常没有可拆的词根，**直接留空**，不要硬凑。
   - 不确定某个词根的准确含义时，留空整列，或者只写你有把握的部分。
2. **巧记必须基于真实词素**，不要写谐音段子、不要编故事、不要用「联想成……」这种没有构词依据的助记。
3. **不要修改其他任何列。** `word` / `pos` / `meaning` / `tags` / `frequency` / `example` / `deck` 必须与输入逐字一致，哪怕你觉得原文有错。
4. **不要漏行，不要加行。** 输入多少行就输出多少行，顺序保持。
5. 只输出 CSV，**不要任何解释、前言、总结，不要用 markdown 代码块包裹**。

## 输出格式

表头：

    word,pos,meaning,tags,frequency,example,deck,mnemonic,root,derivation,synonyms

CSV 引用规则：字段里含逗号、换行或双引号时，用双引号把整个字段包起来；字段内部的双引号写成两个 `""`。

## 示例

输入：

    word,pos,meaning,tags,frequency,example,deck
    security,n.,"安全；保证，担保；保护，防护；有价证券

## 如果还想让 AI 顺手修译文（可选）

上面那批例句的中文是机器翻译的，有错译。想一起修的话，在「铁律」后追加这段：

~~~~
## 额外任务：修正 example 的中文译文

`example` 字段里英文句号后的中文是机器翻译的，有错译和语义不通的地方。

- 重新翻译，要求准确、通顺，符合考研阅读的语感。
- **英文原句一个字都不要改**，只改中文。
- 保持「英文 + 一个空格 + 中文」的格式不变。
- 如果英文原句本身就是残句或语义不完整（例如从段落中间截断），**整列留空**，不要硬翻。

注意：这一条与上面的「不要修改其他任何列」冲突，以本条为准 —— 只允许改 `example` 的中文部分。
~~~~

## 几点提醒

- **别指望一次跑完 3265 个词。** 分批是质量的关键，不是效率的妥协。
- **留空率会很高，这是正常的。** 如果 AI 给几乎所有词都编出了漂亮的词根，说明它在编 —— 尤其是 `about`、`some`、`very` 这类词。
- **抽查方法**：挑 5 个你本来就认识的词（比如 `import` / `export` / `preview`），看它拆的词根对不对。拆错了一看就知道。
- **近义词那一列最容易被浪费。** 模型很爱写库外的词（`significant` 之于 `important`），而我们只能连库内已有的词。所以务必把清单附上，并且抽查几行看看它写的是不是清单里的词。
- 补完的列可以直接用应用导入（表头 `mnemonic` / `root` / `derivation` / `synonyms` 都能被自动识别）。**重复导入不会覆盖已有进度**，所以可以分批导入、逐步补全。
- 导入会自动重建一次词语关联。补完 `root` 列后，卡片的「同根词」才会出现内容；补完 `synonyms`，「近义词」才有。

### 顺带生成近义词清单

一次性把全库 headword 抽出来给模型当白名单：

```bash
python -c "
import csv
rows=list(csv.DictReader(open(r'外部资源/k3y-考研词库-L0-L2.csv',encoding='utf-8-sig')))
open('headwords.txt','w',encoding='utf-8').write('\n'.join(r['word'] for r in rows))
print(len(rows))
"
```
